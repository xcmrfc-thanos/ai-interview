# 聊天记录总结

## 1. 当前项目了解

**项目名称：AI面试官系统**

基于 Flask 的智能面试平台，面向求职者和企业两类用户：

- **求职者**：简历上传与分析、智能模拟面试、面试表现报告、AI 虚拟面试官交互
- **企业**：应聘者管理、面试评分权重设置、职位管理、面试管理

技术栈：Flask 3.0.3 + MySQL + 阿里百炼/kimi + Flask-SocketIO + 讯飞语音服务

项目地址：https://gitee.com/uorol123/ai-interview

---

## 2. 能否改造成"面试猫"类产品

**结论：当前项目完全可以改造，基础重合度高。**

当前项目已有能力：简历解析、AI 模拟面试、数字人面试官、面试评估报告、企业后台、职位管理、评分权重。

与面试猫的差距主要在：现代前端体验、面试题库、多轮面试场景、报告可视化、回放复盘、岗位匹配、商业化体系。

建议改造重点：前端重构、补充题库和 JD 数据、优化 Prompt 和评分维度、增加记录/回放/可视化、接入更稳定的 TTS/ASR。

## 4. 用户期望的产品功能

用户个人需要的功能：

1. **创建面试**：填写公司、岗位基本信息和要求，上传简历
2. **远程线上面试辅助**：手机打电话/视频面试时，电脑实时监听面试官提问，参考提问和简历给出最优答案，对话形式
3. **模拟面试**（类似面试猫）：点击创建的面试跳转模拟面试，AI 实时提问，用户回答后展示参考答案和自己回答的打分
4. **简历优化**：选择已上传简历，创建岗位方向/要求，对照 JD 优化简历

### 功能改造难度评估

| 功能 | 当前基础 | 难度 |
|---|---|---|
| 创建面试（公司/岗位/要求） | 有 Job 模型 | 低 |
| 上传简历 | 已有完整功能 | 低 |
| 远程面试实时辅助 | 没有 | 中高 |
| 模拟面试（提问/回答/参考答案/打分） | 已有 AIInterview 流程 | 低 |
| 简历优化 | 已有分析评分，缺优化改写 | 低 |

远程实时辅助的实现方案：浏览器麦克风采集 + 实时 ASR + LLM 生成答案，或虚拟音频线/APP 辅助更稳定。

## 5. 实施计划

已生成详细实施计划，保存于：

**`docs/superpowers/plans/2026-08-19-interview-copilot-plan.md`**

### 计划范围（MVP）

- 面试计划管理（创建/列表/删除，关联简历）
- 模拟面试（AI 提问 -> 用户回答 -> 参考答案 + 多维度评分）
- 简历优化（选择简历 + 岗位 JD -> 对照优化）
- 远程实时辅助作为二期功能，不在本 MVP 内

### 任务清单

| Task | 内容 | 涉及文件 |
|---|---|---|
| 1 | 新增 InterviewPlan 数据模型 | `models/InterviewPlan.py` |
| 2 | 新增 MockInterviewRecord 数据模型 | `models/MockInterviewRecord.py` |
| 3 | 面试计划 CRUD API | `routes/route_interview_plan.py` |
| 4 | 模拟面试 API | `routes/route_mock_interview.py` |
| 5 | 简历优化 API | `routes/route_resume_optimize.py` |
| 6 | 面试计划管理页 | `templates/applicant/interview_plans.html` |
| 7 | 模拟面试对话页 | `templates/applicant/mock_interview.html` |
| 8 | 简历优化页 | `templates/applicant/resume_optimize.html` |
| 9 | 注册 Blueprint 并集成检查 | `routes/__init__.py` |
| 10 | 端到端走查 | 手动验证全流程 |

预计工作量约 **1 周内出 MVP**，主要复用现有 Flask + SQLAlchemy + LLM 流程。

### 执行方式（待用户选择）

1. **Subagent-Driven（推荐）**：按任务逐个派发独立子代理执行，每任务完成后检查再继续
2. **Inline Execution**：当前会话连续执行所有任务，关键节点确认
