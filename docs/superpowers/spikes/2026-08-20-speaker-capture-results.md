## mica-voice 检查

- JDK 版本：当前环境检测为 Java 8；仓库源码声明 Java 8 baseline。
- 模型：`x-asr-zh-en-chunk-960ms` 已加载，网关监听 `ws://127.0.0.1:18080/mica/voice/ws/online-asr`。
- 文件音频首字延迟：1320ms（28 秒样本）和 1245ms（5.65 秒中文问题），超过 1 秒目标。
- 文件音频最终转写：可返回；中文问题 final 为 5795ms。
- CPU/内存：未验证
- VAD 结束事件：通过显式 stop 得到 final；自动端点结束未单独验证。
- 错误/重连：修复 Spring `ConcurrentHashMap` 写入 null 导致的 WebSocket 1011；真实短暂断网重连仍未验证。
