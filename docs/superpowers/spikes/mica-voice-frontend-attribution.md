# mica-voice 前端参考说明

本项目的 Copilot 录音采集流程参考了 `dreamlu/mica-voice` 的 Spring Web 示例，使用其公开的浏览器麦克风、PCM16 重采样和实时识别事件处理思路。

来源：<https://gitee.com/dreamlu/mica-voice>

mica-voice 使用 Apache License 2.0。当前项目没有复制其完整控制台页面，仅参考并改写了实时录音技术流程；Copilot 的页面布局、业务交互和事件状态处理属于当前项目代码。

如果后续直接分发来源仓库中的代码或修改文件，需要继续保留 Apache 2.0 许可证、版权和修改说明。
